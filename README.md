# Hit'Ems

- テニスのトーナメント進行と結果予想を楽しめるWebアプリケーション
- 大会運営
- トーナメント進捗状況のリアルタイム確認
- トーナメントの予想

## 機能

- 大会の作成・進行
- トーナメントの勝敗予想

## 技術スタック

- 言語：Ruby 3.4
- フレームワーク：Rails 8.1
- DB：SQLite
- トーナメント描画用：Bracketry

## セットアップ

```bash
bundle install
bin/rails db:migrate
bin/rails db:seed      # サンプルデータ投入（任意）
bin/rails server
```

## テスト

```bash
bin/rails test
```
